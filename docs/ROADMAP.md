# Metis Public Roadmap

This roadmap is intentionally high level.

## v0.1 — Core local developer experience

Focus:

- RAG environment scaffolding
- Agent environment scaffolding
- MCP server scaffolding
- capability composition
- project metadata
- project inspection
- local environment diagnostics

Core commands:

```text
metis init rag
metis init agent
metis init mcp-server
metis add rag
metis inspect
metis doctor
```

## Next areas of exploration

Potential future areas include:

- more reusable capabilities
- more recipes
- easier package installation
- richer compatibility checks
- improved reconciliation
- generated project upgrades
- more framework choices
- deployment-oriented workflows

The roadmap may change based on contributor feedback and real-world usage.
